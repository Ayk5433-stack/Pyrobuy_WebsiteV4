PYROBUY WEBSITE — IMAGE FOLDER

HOW TO USE
1. Upload this whole folder (index.html + images) to HostGator → File Manager → public_html, so index.html sits directly in public_html.
2. To add a picture, save it into the folder shown below using EXACTLY the file name listed (lowercase, same .jpg/.png ending).
   The website already points to these names, so it appears automatically. Create the folder (about, banners…) if it is missing.
3. Spots without a file show a clean dark box (brand cards show the brand name) until you add the image.
4. Images can also be uploaded from the site editor (yoursite.com/#/editor); those take priority over files here.
